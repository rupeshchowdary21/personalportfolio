# Personal Portfolio Project (Review 2 Ready)

This is a Vite + React + Bootstrap front-end web application built for **Review 2 (End-Semester Hackathon)** evaluation.

## How to Run in VS Code

1. Extract the downloaded `personal-portfolio.zip` file.
2. Open VS Code and go to **File > Open Folder...**, then select the extracted `personal-portfolio` folder.
3. Open the VS Code terminal (`Ctrl + ~` or `Cmd + ~`).
4. Install dependencies:
   ```bash
   npm install
   ```
5. Start the development server:
   ```bash
   npm run dev
   ```
6. Open the browser link provided in the terminal (usually `http://localhost:5173`).

## Project Evaluation Features
- **Modular Component Architecture**: Located under `src/components/`.
- **Centralized Portfolio Data**: Managed inside `src/data/portfolioData.js`.
- **Responsive UI**: Built with Bootstrap 5 grid utilities.
- **Interactive Features**: Dynamic project category filtering and quick-contact suggestion auto-fill.
